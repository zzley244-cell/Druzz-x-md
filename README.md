**Steps to fork:**

1. Open the GitHub repository using the GitHub icon in the navigation above.
2. Click the **Fork** button on the repository page.
3. Select your own GitHub account as the destination.
4. Wait for GitHub to finish creating your fork.
5. Open your newly created fork.
6. ⭐ Star the original repository to support the project.

<br>

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:00c8ff,100:7c4dff&height=60&text=%F0%9F%93%A5%20CLONE&fontSize=22&fontColor=ffffff&fontAlignY=68" width="100%">

Clone the project to your local machine:

```bash
git clone https://github.com/DruzzLabs/Druzz-x-md.git
cd Druzz-x-md
npm install
```

<br>

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:7c4dff,100:ff00e6&height=60&text=%F0%9F%9B%A0%EF%B8%8F%20INSTALLATION&fontSize=22&fontColor=ffffff&fontAlignY=68" width="100%">

Make sure you have **Node.js** installed, then run:

```bash
npm install
```

This installs all required dependencies defined in `package.json`.

<br>

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:ff6a00,100:ff00e6&height=60&text=%E2%9A%99%EF%B8%8F%20CONFIGURATION&fontSize=22&fontColor=ffffff&fontAlignY=68" width="100%">

DRUZZ X-MD is configured using environment variables.

1. If a `.env.example` file exists in the project, copy it:

```bash
cp .env.example .env
```

2. Open `.env` and fill in the values required by the project.
3. Save the file before starting the bot.

> ⚠️ **Security Notice:** Never publish, commit, or share your `.env` file, session files, tokens, passwords, or API keys publicly. Treat all credentials as private and confidential.

<br>

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:39ff88,100:00fff9&height=60&text=%E2%96%B6%EF%B8%8F%20LOCAL%20RUN&fontSize=22&fontColor=0d0221&fontAlignY=68" width="100%">

After installing dependencies and configuring your environment file, start the bot:

```bash
npm start
```

Follow the on-screen instructions to link/authenticate your WhatsApp session.
