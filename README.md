## 💻 STEP 2 — Clone Your Fork

Install **Git** and **Node.js** first.

Then open Terminal / CMD and run:

```bash
git clone https://github.com/DruzzLabs/Druzz-x-md.git
```

Enter the project:

```bash
cd druzz-x-md
```

Install dependencies:

```bash
npm install
```

If the project uses a lockfile, prefer:

```bash

```

## 🐛 Troubleshooting

### ❌ `npm install` fails

Check:

```bash
node -v
npm -v
```

Then review the error shown by npm.

### ❌ Railway build fails

Check:

- `package.json`
- Node.js version
- Start command
- Required environment variables
- Railway deployment logs

### ❌ Bot starts then stops

Check the runtime logs for:

- Missing environment variables
- Invalid credentials
- Authentication/session errors
- Missing dependencies
- Incorrect start command

### ❌ Bot does not connect to WhatsApp

Verify the authentication/session mechanism used by this repository and follow the project's own connection instructions.
